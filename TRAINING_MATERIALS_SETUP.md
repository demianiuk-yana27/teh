# Навчальні матеріали — налаштування

Реалізація знаходиться у гілці `feature/netlify-frontend`. Старі навчальні підрозділи «Коробки» та «Скасування та об’єднання замовлень» не змінено.

## 1. D1 (використовує наявну базу задач)
Cloudflare → D1 → база `tech-manager-tasks` → Console. Виконайте SQL із `migrations/0002_training_materials.sql`. Наявний binding `TASKS_DB` залишається без змін.

## 2. R2 для фото та відео
Cloudflare → R2 → Create bucket, наприклад `tech-training-media`. У Pages project `teh` → Settings → Bindings → Add → R2 bucket, variable name **`TRAINING_MEDIA`**, виберіть створений bucket. Додайте для Production (та Preview, якщо потрібно). Якщо R2 вимагає підключення платіжного методу або активації, виконайте відповідні дії у своєму Cloudflare акаунті. Не робіть bucket публічним.

## 3. Публікація
Redeploy Pages production branch `feature/netlify-frontend`. Після деплою відкрийте «База даних → Навчальні матеріали». Бос створює, редагує, публікує та видаляє матеріали. Менеджери читають лише опубліковані.

Редактор підтримує текст, списки, фото (JPEG/PNG/WebP/GIF), відеофайли (MP4/WebM/MOV) до 50 МБ і посилання YouTube/Vimeo. Зберігання метаданих — D1, приватних файлів — R2. Файли віддаються лише авторизованим ролям через Pages Functions.

**Обмеження:** великі відео понад 50 МБ не завантажуються; для них використовуйте YouTube/Vimeo. Наразі видалення матеріалу не очищає автоматично завантажені медіафайли в R2. Завантажені відео повинні мати браузерно-сумісний кодек. Збереження чернетки та публікація потребують доступної D1; завантаження файлів потребує R2. Доступ за роллю захищено сервером; не зберігайте паролі у GitHub.
