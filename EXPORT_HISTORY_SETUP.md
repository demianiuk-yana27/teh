# Журнал підтверджених вигрузок для дашборду керівника

Зміни виконані лише в гілці `feature/netlify-frontend`.

## Налаштування
1. У **Cloudflare Pages → Settings → Variables and Secrets** додайте **секрет** `EXPORT_EVENT_SECRET`. Це довгий випадковий рядок, окремий від TTN_API_SECRET.
2. У **Render → Environment** додайте:
   - `EXPORT_EVENT_URL` = `https://teh-7rt.pages.dev/export-completed`
   - `EXPORT_EVENT_SECRET` = **точно той самий секрет**, що в Cloudflare.
3. Розгорніть оновлений код **Cloudflare Pages** та **Render**.
4. Запустіть тестову вигрузку і дочекайтеся завершення; у «Дашборд керівника» натисніть «Оновити».

## Як це працює
- Render повідомляє Cloudflare про **підтверджене успішне завершення** після повернення функції вигрузки. Відкритий браузер не потрібен.
- Подія має унікальний `run_id`, тож повторна доставка не створює дубль.
- Cloudflare перевіряє секрет, валідує тип і кількість та зберігає запис у D1 (`TASKS_DB`).
- При недоступності Cloudflare Render повторює запит тричі та залишає помилку в логах. Після вичерпання спроб потрібне ручне відновлення запису; безперервної черги наразі немає.
- Для «Доробок» кількість — **додані замовлення**; КТВ і «Відгуки» — **оброблені рядки**; «Негативні відгуки» — **додані відгуки**; «Звіт по кількості замовлень» — **записані статуси**, не кількість замовлень.
- Дашборд доступний тільки ролі `boss`; серверний callback захищено окремим секретом.
- Події до налаштування секретів заднім числом не відновлюються.
