# Дошка задач — підключення Cloudflare D1

Код дошки вже є у гілці `feature/netlify-frontend`. Для спільного збереження задач необхідно один раз підключити D1.

1. Cloudflare Dashboard → Storage & databases → D1 → Create database. Назва: `tech-manager-tasks`.
2. У створеній базі відкрийте Console і виконайте SQL з файлу `migrations/0001_manager_tasks.sql`.
3. Workers & Pages → Pages → `teh` → Settings → Bindings → Add → D1 database.
4. Variable name **`TASKS_DB`** (точно так), виберіть базу `tech-manager-tasks`. Додайте binding для **Production** (і Preview, якщо потрібен тестовий деплой).
5. Зробіть Redeploy останнього деплою Cloudflare Pages. Переконайтеся, що production branch — `feature/netlify-frontend`.

Менеджер обирає ім’я у браузері; це відображуване ім’я, а не окремий захищений обліковий запис. Усі менеджери та бос бачать спільну дошку і можуть відмічати задачі виконаними.

Нагадування перевіряються щохвилини, поки сторінка відкрита. За дозволом браузера з'являються системні сповіщення, коли до дедлайну ≤ 1 години або він минув. **При повністю закритому сайті сповіщення не доставляються** — для цього потрібна окрема push-підписка, service worker та фоновий планувальник.

Паролі та інші секрети у репозиторій не додавати.
